# iOS App Workspace

This folder is reserved for the native iOS app, kept separate from `html prototype/`.

Recommended layout:

- `Vibrise/` - main iOS app source
- `VibriseTests/` - unit tests
- `VibriseUITests/` - UI tests

Suggested source structure inside `Vibrise/`:

- `App/`
- `Core/`
- `Features/`
- `Resources/`

The actual Xcode project/workspace file should be created from Xcode and placed in this `ios/` folder.
